Exponents, Roots, and Logarithms Reference Sheet
==================================================

	b^0 = 1
	b^1 = b
	b^2 = b * b

	(b^x)(b^y) = b^[x + y]
	(b^x)^y = b^[xy]
	(b^x)(a^x) = (ab)^x

	b^-x = 1/b^x

	b^[y/x] = root^x(b^y)
	b^[1/x] = a  <=>  a^x = b

	sqrt(bb) = |b|
	b^[1/x] = |b|  where (x) is even

---

	log[b](a) = x  <=>  b^x = a
	log[b](1) = 0  <=>  b^0 = 1
	log[b](b) = 1  <=>  b^1 = b

	log[b](x <= 0) = undefined

	log(xy) = logx + logy
	log(x/y) = logx - logy
	log(x^y) = ylogx

	log[b](x) = 1 / log[x](b)
	log[b](x) = log[a](x) / log[a](b)

	b^[ylog[b](x)] = x^y

	ln(x) = log[e](x)
