Fundamental Properties Reference Sheet
==================================================

	x + y = y + x
	(x + y) + z = x + (y + z)
	x + x = 2x
	x + 0 = x

	x - y = x + (-1)y
	x - x = 0
	x - 0 = x

	xy = yx
	(xy)z = x(yz)
	x * 1 = x

	a(x + y) = ax + ay

	x / y = x * (1/y)
	x / 1 = x
	x / y = (ax) / (ay)
	(x/y) * (a/b) = (ax) / (by)
