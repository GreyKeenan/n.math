The Derivative of a Vector Function
========================================

Consider some vector function `v(t)`,
and say that it describes some curve `C` in 3d space.
The derivative of that vector function at `t0`
will output a vector who is tangent to `C` at `t0`.
That follows from our concept of a derivative, after all.

Numerically, the derivative is defined as:

	v(t) = < p, q, r >
	dv/dt = <  dp/dt, dq/dt, dr/dt  >

Similarly, the partial-derivative of a vector function is:

	let a be the partial symbol

	v(s,t) = < p, q, r >

	av/at = <  ap/at, aq/at, ar/at  >
	av/as = <  ap/as, aq/as, ar/as  >
