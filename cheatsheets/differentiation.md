Differentiation Cheat-Sheet
==================================================

Definition

	f'(x) = lim[h->0] (f(x + h) - fx) / h
	f'(x) = lim[x->a] (fx - fa) / (x - a)

Differentiation Rules

	for differentiating with respect to x
	let f and g be functions of x
	let c be constant (non-function-of-x)

	(c)' = 0
	(cf)' = cf'
	(f + g)' = f' + g'

	(x)' = 1

	(f^c)' = cf^[c - 1] f'
	(c^f)' = lnc c^f f'

	log[c]'(f) = (1/(lnc f)) f'

	(fg)' = f'g + fg'
	(f/g)' = (f'g - fg') / g^2
	(f^g)' = (f^g)(g'lnf + gf'/f)

	( f(g(x)) )' = f'(g(x)) g'(x)

Less-Generalized Rules

	(x^c)' = cx^[c - 1]
	(x^x)' = (x^x)(lnx + 1)

	(e^f)' = e^f f'
	(e^x)' e^x
	ln'(|x|) = 1/x
