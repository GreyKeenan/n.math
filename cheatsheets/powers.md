Powers Cheat-Sheet
========================================

Exponents and Roots

	x^0 = 1
	x^1 = x

	(b^x)(b^y) = b^[x+y]
	(b^x)^y = b^[xy]
	(b^x)(a^x) = (ab)^x

	b^[-x] = 1 / b^x
	b^[1/x] = root[x](b)

	root[z](b^z) = b;   when z is odd
	root[z](b^z) = |b|; when z is even

Logarithms

	log[b](a) = x  <=>  b^x = a
	log[b](1) = 0  <=>  b^0 = 1
	log[b](b) = 1  <=>  b^1 = b

	log[b](z)  is undefined if  z <= 0

	log(1/x) = -log(x)
	log(xy) = logx + logy
	log(x/y) = logx - logy
	log(x^y) = ylogx

	b^[log[b](x)] = x

	log[a](x) / log[a](b) = log[b](x)
	1 / log[x](b) = log[b](x)

	ln(x) = log[e](x)
