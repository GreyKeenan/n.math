--------------------------------------------------

n :ce: {ZZ}

BUT ALSO:
cos(-8x + 2:pi:n) = -1/6

/      arccos(-1/6) - 2:pi:n

Building off of the above equations,
can define all values of 'x' that are in [-pi/2, 0]?

(He does trial & error with a table of `n` values.


My Approach
--------------------------------------------------

+/- x = arccos(-1/6)/8 - :pi:n/4

x ~= +/- (0.22 - :pi:n/4)
(approximation done in the video to simplify things)

+/- (0.22 - :pi:n/4) >= -pi/2
+/- (0.22 - :pi:n/4) <= 0

---

0.22 - :pi:n/4 >= -pi/2
-:pi:n/4 >= -pi/2 - 0.22
:pi:n/4 <= pi/2 + 0.22
:pi:n <= 2pi + 0.88
n <= 2 + 0.88/pi

0.22 - :pi:n/4 <= 0
-:pi:n/4 <= -0.22
:pi:n/4 >= 0.22
:pi:n >= 0.88
n >= 0.88/pi

---

-0.22 + :pi:n/4 >= -pi/2
:pi:n/4 >= -pi/2 - 0.22
:pi:n >= -2pi + -0.88
n >= -2 + -0.88/pi

-0.22 + :pi:n/4 <= 0
:pi:n/4 <= 0.22
n <= 0.88/pi

---

for x = arccos(-1/6)/8 - :pi:n/4,
if x >= -pi/2 & x <= 0,
n <= 2 + 0.88/pi & n >= 0.88/pi

for -x = arccos(-1/6)/8 - :pi:n/4,
if x >= -pi/2 & x <= 0,
n >= -2 + -0.88/pi & n < 0.88/pi

n :ce: {Zintegers}
