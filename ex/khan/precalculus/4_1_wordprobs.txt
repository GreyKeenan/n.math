Problem 5
==================================================

A factory has a batch of hand sanitizer with 50% alcohol.
How much pure (100%) acohol should they include in a
600mL bottle to make a 68% mixture?

---

 0.5x + p     600 * 0.68
---------- = ------------
  x   + p        600

solve for p

0.5x + p = 408
x/2 = 408 - p
x = 816 - 2p

x + p = 600
x = 600 - p

600 - p = 816 - 2p
600 + p = 816
p = 216                   <---

x = 384

check:

 0.5x + p     600 * 0.68
---------- = ------------
  x   + p        600

 384/2 + 216     408
------------- = -----
 384 + 216       600

	384/2 = 192
	192 + 216 = 408
