Lesson Chapter Structure Things
==================================================

The course is broken down into units.
They are as follows:

1. Composite and Inverse Functions
2. Trigonometry
3. Complex Numbers
4. Rational Functions
5. Conic Sections
6. Vectors
7. Matrices
8. Probability and Combinatorics
9. Series
10. Limits and Continuity

Each unit has separate lessons.
Lessons may contain any number of exercises.

Each unit has a couple "quiz" exercises, which are numbered.
I am using the numbers to denote sub-secions of units.
Each unit also has a single "test" exercise which ends it.

The stuff documented in this directory is work from the exercises.
Not all work is here, since some of it was on paper.
Lesson notes are incorporated into the general notes in this repo.

> Also note that I didn't organize this stuff really until unit 4.
