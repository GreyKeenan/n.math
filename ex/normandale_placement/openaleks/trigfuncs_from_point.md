How I would try to do it:
==================================================

	terminal_side_point = (x, y)

	t = tanA
	s = sinA
	c = cosA

we know:

	t = s/c = y/x
	ss = 1 - cc
	cc = 1 - ss

so:

	y/x = s / root(1-ss)

NOTE: I didn't consider zero-cases.


How lesson shows to do it
==================================================

	given point on the terminal side = (x, y)

	let h = root(xx + yy)    the length of the vector

	sinA = y/h
	cosA = x/h

	tanA = y/x, x != 0


Essentially, this is the same as what I was doing,
but in more direct terms & with fewer middleman steps.
Its ... much faster than what I was doing before lol.
